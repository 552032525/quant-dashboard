# 模块四：智能资金监控 设计文档

> **状态**: 设计中 | **日期**: 2026-06-08 | **版本**: 1.0

## 目标

构建智能资金流向监控模块，覆盖个股资金流、北向资金、板块资金排名、大盘资金总览，并集成 AI 资金面解读，帮助用户洞察主力动向和资金趋势。

## 当前状态

- 模块一（行情）、模块二（基本面）、模块三（技术面）均已完成
- 数据源使用新浪/腾讯免费 API（东方财富 API 在本地网络被阻断）
- 前端已有完整组件体系（ECharts + Tailwind + Pinia）

### 后端 API

新增 `/api/fundflow` 路由：

| 端点 | 方法 | 说明 |
|------|------|------|
| `/stock/{code}` | GET | 个股资金流向（近20日逐日主力/散户净流入） |
| `/northbound` | GET | 北向资金流向（近期每日沪股通/深股通净买入） |
| `/northbound/daily` | GET | 当日北向资金概况 |
| `/sectors` | GET | 板块资金流向排名（流入TOP10 + 流出TOP10） |
| `/market` | GET | 大盘资金总览（今日主力/散户净流入汇总） |
| `/report` | POST | AI 资金面研报（注入资金流数据） |

### 数据源

使用新浪免费 API 获取资金流向数据：

| 数据类型 | 来源 | 说明 |
|---------|------|------|
| 个股资金流 | Sina MoneyFlow API | 每日主力/超大单/大单/中单/小单净流入 |
| 北向资金 | Tencent ff_hsgt | 沪股通/深股通每日净买入 |
| 板块资金流 | Sina Sector API | 行业板块资金流入/流出排名 |
| 大盘资金流 | 多源聚合计算 | 全市场资金净流入汇总 |
