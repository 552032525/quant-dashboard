# 模块三：AI 技术面智能分析 设计文档

> **状态**: 已确认 | **日期**: 2026-06-07 | **版本**: 1.0

## 目标

将现有 AI 基础分析升级为产品级技术面智能分析，实现 AI 形态识别、多指标量化打分、自动支撑压力位、量价异动捕捉四大子功能。

## 当前状态

- `POST /api/ai/analyze` — 发送 OHLC 数据给 GPT，返回 200 字简要分析
- `POST /api/ai/chat` — 通用 AI 对话，可选标的上下文
- `KLineChart.vue` — 基础蜡烛图（无叠加指标）
- 无本地指标计算能力，完全依赖 GPT

### 后端 API

新增 `/api/technical` 路由：

| 端点 | 方法 | 说明 |
|------|------|------|
| `/indicators/{code}` | GET | 预计算 MACD/RSI/KDJ/BOLL/MA/量，返回完整指标数据 |
| `/anomaly/{code}` | GET | 量价异动检测 |
| `/report` | POST | AI 技术面研报（注入指标数据） |
| `/score` | POST | 量化多维度打分 |

### 指标计算

服务端用纯 Python 计算，不依赖第三方库：

```
EMA12/26 → MACD(DIF/DEA/BAR)
RSI(6/12/24) = 100 - 100/(1 + avg_gain/avg_loss)
KDJ: RSV → K/D/J 递推
BOLL: MA20 ± 2*std
MA: SMA(5/10/20/60)
量价异动: 放量>2x均量 + 涨幅>5% / 缩量<0.5x均量 + 十字星
```

### 量化打分

5 个维度，每项 0-20 分，总分 100：

| 维度 | 判断逻辑 |
|------|---------|
| 趋势 | MA多头排列(20) / 金叉形成中(10) / 空头(0) |
| 动量 | RSI 50-70(15) / MACD 金叉(20) / 顶背离(0) |
| 波动 | BOLL 中轨上方(15) / 收口(10) / 下轨(0) |
| 量能 | 放量上涨(20) / 缩量下跌(5) / 缩量横盘(10) |
| 综合 | 前四项加权平均 |
